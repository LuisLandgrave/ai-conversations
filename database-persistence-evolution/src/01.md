## 🧩 What SQL *is*  
SQL (**Structured Query Language**) is a declarative language:  
You tell the database **what you want**, not **how to do it**.  
The database engine figures out the “how.”

---

## 🗂️ The Core Mental Model  
A database contains **tables**.  
Tables contain **rows**.  
Rows contain **columns**.

Think of a spreadsheet — but with superpowers.

Example table: `users`

| id | name | age | city |
|----|------|-----|------|
| 1  | Ana  | 28  | CDMX |
| 2  | Luis | 34  | Coacalco |
| 3  | Mei  | 22  | Osaka |

---

## 🧱 SQL Building Blocks (The Essentials)

### 1) **SELECT** — get data  
```sql
SELECT name, age
FROM users;
```

### 2) **WHERE** — filter rows  
```sql
SELECT *
FROM users
WHERE age > 30;
```

### 3) **ORDER BY** — sort  
```sql
SELECT *
FROM users
ORDER BY age DESC;
```

### 4) **LIMIT** — restrict number of results  
```sql
SELECT *
FROM users
LIMIT 5;
```

### 5) **INSERT** — add data  
```sql
INSERT INTO users (name, age, city)
VALUES ('Carlos', 29, 'Monterrey');
```

### 6) **UPDATE** — modify data  
```sql
UPDATE users
SET age = 35
WHERE name = 'Luis';
```

### 7) **DELETE** — remove data  
```sql
DELETE FROM users
WHERE id = 3;
```

---

## 🔗 Joins (The Most Important Concept After SELECT)

Databases often split data into multiple tables.  
**Joins** let you combine them.

Example:

`orders`  
| id | user_id | total |
|----|---------|-------|
| 1  | 2       | 450   |
| 2  | 1       | 120   |

### INNER JOIN — match rows between tables  
```sql
SELECT users.name, orders.total
FROM users
JOIN orders ON users.id = orders.user_id;
```

---

## 📊 Aggregations (Counting, Summing, Grouping)

### COUNT  
```sql
SELECT COUNT(*) FROM users;
```

### SUM  
```sql
SELECT SUM(total) FROM orders;
```

### GROUP BY  
```sql
SELECT city, COUNT(*) AS num_users
FROM users
GROUP BY city;
```

---

## 🧠 The SQL Query Execution Order (Non‑obvious but crucial)

Even though you *write* SQL in this order:

```sql
SELECT
FROM
WHERE
GROUP BY
HAVING
ORDER BY
LIMIT
```

The database *executes* it in this order:

1. FROM  
2. WHERE  
3. GROUP BY  
4. HAVING  
5. SELECT  
6. ORDER BY  
7. LIMIT  

This explains why you can’t use column aliases in `WHERE` but can in `ORDER BY`.

## 🏛️ Types of SQL Databases  
SQL is a language, not a database.  
Different systems implement it:

- PostgreSQL (most powerful open-source)
- MySQL / MariaDB (common in web apps)
- SQLite (lightweight, file-based)
- SQL Server (Microsoft)
- Oracle (enterprise)

All share the same fundamentals.
