# 🧩 Side‑by‑Side Comparison: Same Feature, Different JVM Languages

---

## 1️⃣ **Java (baseline)**  

Verbose, explicit, safe, but ceremony-heavy.

```java
public class User {
    private final int id;
    private final String name;

    public User(int id, String name) {
        this.id = id;
        this.name = name;
    }

    public String getName() { return name; }
}

CompletableFuture<User> fetchUser(int id) {
    return CompletableFuture.supplyAsync(() -> new User(id, "Luis"));
}

public static void main(String[] args) {
    fetchUser(42).thenAccept(user -> {
        String name = user.getName();
        System.out.println(name != null ? name.length() : "unknown");
    });
}
```

### What you feel here  

- Lots of boilerplate (getters, constructor).  
- Null checks are manual.  
- Async code uses callbacks → nesting.  

---

## 2️⃣ **Kotlin — concise, null‑safe, coroutine‑friendly**

```kotlin
data class User(val id: Int, val name: String?)

suspend fun fetchUser(id: Int): User {
    return User(id, "Luis")
}

fun main() = runBlocking {
    val user = fetchUser(42)
    println(user.name?.length ?: "unknown")
}
```

### What Kotlin brings  

- `data class` auto‑generates everything.  
- `String?` makes null explicit.  
- `?.` and `?:` eliminate NPE boilerplate.  
- Coroutines make async code look synchronous.  

**Feels like Java without the pain.**

---

## 3️⃣ **Scala — functional, expressive, powerful**

```scala
case class User(id: Int, name: Option[String])

import scala.concurrent._
import ExecutionContext.Implicits.global

def fetchUser(id: Int): Future[User] =
  Future(User(id, Some("Luis")))

fetchUser(42).map { user =>
  println(user.name.map(_.length).getOrElse("unknown"))
}
```

### What Scala brings  

- `Option` replaces null entirely.  
- Pattern matching, immutability, FP style.  
- Futures integrate with functional pipelines.  

**Feels like a functional language on the JVM.**

---

## 4️⃣ **Groovy — dynamic, flexible, scripting‑friendly**

```groovy
class User {
    int id
    String name
}

def fetchUser = { id ->
    new User(id: id, name: "Luis")
}

def user = fetchUser(42)
println user.name?.length() ?: "unknown"
```

### What Groovy brings  

- Dynamic typing → less ceremony.  
- Optional semicolons, closures, simple syntax.  
- Safe navigation `?.` like Kotlin.  
- Great for DSLs (Gradle), scripting, glue code.

**Feels like Python/Ruby on the JVM.**

---

## 5️⃣ **Clojure — immutable, concurrent, Lisp‑style**

```clojure
(defn fetch-user [id]
  {:id id :name "Luis"})

(let [user (fetch-user 42)]
  (println (if-let [n (:name user)]
             (count n)
             "unknown")))
```

### What Clojure brings  

- Immutable maps instead of classes.  
- No nulls unless you introduce them.  
- Very concise, very expressive.  
- Concurrency primitives (atoms, refs, agents).  

**Feels like a functional Lisp with superpowers.**
