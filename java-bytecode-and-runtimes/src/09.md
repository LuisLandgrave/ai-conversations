# 🌱 **OPEN SOURCE JVMs & JDKs (Free, Open Source Licenses)**  

These are fully open source, free to use, redistribute, and containerize.  
Some have optional paid support, but the runtime itself is free.

### ✔ **OpenJDK (HotSpot JVM)**  

- **License:** GPLv2 + Classpath Exception  
- **Cost:** Free  
- **Notes:** The reference implementation; most vendors build from this.

### ✔ **Eclipse Temurin (Adoptium)**  

- **License:** GPLv2 + Classpath Exception  
- **Cost:** Free  
- **Notes:** Community-driven, stable, widely used in production.

### ✔ **BellSoft Liberica JDK**  

- **License:** GPLv2 + Classpath Exception  
- **Cost:** Free (paid support optional)  
- **Notes:** Includes LibericaFX, embedded variants, Alpine support.

### ✔ **Microsoft Build of OpenJDK**  

- **License:** GPLv2 + Classpath Exception  
- **Cost:** Free  
- **Notes:** Microsoft’s hardened OpenJDK build for Azure & enterprise.

### ✔ **Eclipse OpenJ9 (JVM)**  

- **License:** EPL 2.0  
- **Cost:** Free  
- **Notes:** Alternative JVM with lower memory footprint.

# 🏢 **VENDOR / COMMERCIAL JVMs & JDKs (Paid or Enterprise-Supported)**  

These are **not fully open source** or include **commercial features**, **paid support**, or **proprietary GC technology**.

### 💼 **Oracle JDK**  

- **License:** Oracle No-Fee Terms for Development & Testing  
- **Cost:** Free for dev/test; **paid for production**  
- **Notes:** Same codebase as OpenJDK but with proprietary extras.

### 💼 **Azul Platform Prime (formerly Zing)**  

- **License:** Commercial  
- **Cost:** Paid  
- **Notes:** Proprietary C4 GC, ultra-low latency, enterprise-grade.

### 💼 **Amazon Corretto**  

- **License:** GPLv2 + Classpath Exception  
- **Cost:** Free  
- **Notes:** Vendor-supported OpenJDK; not commercial, but vendor-backed.

### 💼 **Red Hat Build of OpenJDK**  

- **License:** GPLv2 + Classpath Exception  
- **Cost:** Free (paid support via RHEL subscription)  
- **Notes:** Enterprise-focused, hardened builds.
